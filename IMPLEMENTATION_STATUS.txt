  ✅ Implemented: min_rounds parameter (default 3)

USAGE EXAMPLES
════════════════════════════════════════════════════════════════════════════════

1. Run Single Debate:
   python run_debate_pipeline.py --single

2. Run Batch (5 debates):
   python run_debate_pipeline.py --num-debates 5

3. Custom Configuration:
   python run_debate_pipeline.py \
     --num-debates 10 \
     --min-rounds 3 \
     --max-rounds 10 \
     --output-dir results/experiment

4. Run Tests:
   pytest tests/test_debate_pipeline_v2.py -v

5. Python API:
   from src.orchestrator.debate_pipeline_v2 import DebatePipeline
   from src.utils.debate_api_client import DebateAPIClient
   
   client = DebateAPIClient()
   pipeline = DebatePipeline(api_client=client, min_rounds=3)
   transcript = pipeline.run_full_debate(
       debate_id='test_001',
       question='Is X true?',
       ground_truth='yes'
   )
